# NVFP4 Dequantizer

## Instructions

Implémenter en Zig un déquantiseur NVFP4:
- prend en entrée un fichier .safetensor
- qui déquantise les tensors à la volée
- avec du SIMD qui va bien
- implémenté sous forme de std.Io.Reader
- multicore

Le rendu: un projet GitHub + une visio/un meeting pour expliquer le truc.
